# Bookfly

Bookfly B2B-Portal für den Buchgroßhandel – Web-Anwendung, mit der
registrierte Geschäftskunden (Buchhandlungen) online bestellen können.

## Schulprojekt
Dieses Projekt entsteht im Rahmen der Ausbildung nach IHK-Vorgaben.
Die vollständige Projektdokumentation (Projektantrag, Lastenheft,
Pflichtenheft, ER-Diagramm, Klassendiagramm, Use-Case-Diagramm etc.)
befindet sich im Ordner [`doc/`](doc/).

## Funktionen (geplant)
- Händler-Login / Registrierung mit Verifizierung
- ISBN-Schnellbestellung
- B2B-Katalog mit Nettopreisen und Staffelrabatten
- Warenkorb & Bestellabwicklung
- Kauf auf Rechnung

## Technologie
- PHP
- MySQL
- HTML/CSS/JavaScript

## Projektstruktur
```
BookFly/
├── database/     # DB-Verbindung & Schema
├── includes/     # PHP-Hilfsfunktionen
├── templates/    # Ansichten (Header, Footer, Login, etc.)
├── static/       # CSS, JS, Bilder
└── doc/          # Projektdokumentation
```
